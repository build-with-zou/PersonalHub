# PersonalHub

PersonalHub 是一个轻量、本地优先的个人规划与学习框架，用于和 AI 一起讨论目标、选择下一步、开展学习并复盘。框架使用普通 Markdown 文件，原有课程、科研和项目资料继续保留在原位置。

仓库分成两层：

- 公开层：可复用的 AI 指令、领域定义和模板，可以提交到 GitHub。
- 本地层：个人背景、目标、真实路径、进度和复盘。文件统一以 `.local.md` 结尾，并由 Git 忽略。

## 开始一次对话

从该目录启动 Codex，使它读取根目录的 `AGENTS.md`：

```bash
cd /Users/[用户名]/PersonalHub
codex
```

可以这样开始：

- “我今天有这些截止日期和这些可用时间，帮我判断先做什么。”
- “我想学习一个主题，先和我讨论目标，再分析前置知识和第一步。”
- “从最近状态继续科研工作，帮我确定下一个可以验证的结果。”
- “和我复盘这一周，讨论后再更新计划。”

## 工作流程

```text
目标或问题
      |
      v
讨论意图和限制
      |
      v
查看当前状态和相关资料
      |
      v
选择一个有价值的下一步
      |
      v
学习、练习或执行
      |
      v
记录证据、遗留问题和下一步
```

`DASHBOARD.local.md` 是当前控制面板，各领域的详细状态位于 `areas/`。现有文件通过 `PATHS.local.md` 引用，不复制进本仓库。

## 隐私规则

不要在公开文件中写入真实姓名、学校或实验室、账号信息、私有链接、用户目录的绝对路径、未公开研究细节或个人进度。这些内容必须放入以 `.local.md` 结尾的文件。

发布前运行：

```bash
git status --short --ignored
git ls-files
```

确认 `git ls-files` 的输出中没有任何 `.local.md` 文件，并人工检查即将提交的差异。

## 文件说明

- `AGENTS.md`：AI 的通用协作规则。
- `areas/*/AGENTS.md`：不同领域的规划与教学规则。
- `templates/`：创建本地私有文件时使用的空白模板。
- `reviews/README.md`：复盘节奏和命名约定。
- `docs/ARCHITECTURE.md`：设计原则和扩展方法。
