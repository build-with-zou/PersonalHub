# 复盘

复盘的目的，是根据实际情况更新决定。个人复盘文件必须以 `.local.md` 结尾，确保 Git 自动忽略。

建议节奏：

- 每周：用 10-20 分钟比较计划和实际证据，选择最多三个跨领域重点。
- 每月：重新考虑活跃目标、暂停目标、总体负担和方向。
- 重要里程碑后：记录有效方法、发生的变化和可以复用的经验。

每周复盘使用 `templates/weekly-review.md`，文件名为 `YYYY-Www.local.md`。

每日日志使用 `templates/daily-log.md`，一周一个滚动文件 `YYYY-Www-daily.local.md`，每天追加一个日期段。用 3–5 分钟记录完成证据、阻力和下一步即可，不补造漏记日的内容。

周复盘先看实际日志，再写总结和下一周取舍；未填写模板不算完成复盘。具体日期、时间与提醒启用状态只记录在本地文件中。
